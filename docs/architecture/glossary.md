# Glosario

> **Estado:** Aplicable.

| Término | Significado |
|---|---|
| Edición | Un libro concreto: un archivo con su ficha |
| Huella | `sha256:` del archivo; dice que dos archivos son el mismo libro |
| Locator | La posición de NB Books: `href`, `#char=N`, progresiones y la cita alrededor |
| Motor | El crate `nb-books-lector`, el mismo en el PC y en el teléfono |
| Exportación sellada | La copia del motor en `native/vendor/` con su manifiesto de huellas |
| Corpus de conformidad | El libro inventado y las respuestas grabadas que los dos motores deben reproducir |
| Manifiesto | La lista de cambios del PC desde una versión |
| Lápida | Un cambio del manifiesto que dice que algo se borró |
| Selección | Lo que la persona eligió que llegue al teléfono |
| Pendiente | Lo hecho en el teléfono que el PC aún no confirmó |
| Leer sin descargar | Abrir un libro del PC desde una caché temporal que se recorta sola |
| Leer en el PC | El teléfono como mando del lector de NB Books |
| Libro del teléfono | Un libro añadido desde el teléfono (`origen = telefono`); no sale de él |
