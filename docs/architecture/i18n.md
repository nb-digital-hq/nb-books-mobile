# Internacionalización

> **Estado:** Implementado. Decisión: [ADR-006](../adr/006-internationalization.md).

* El texto fuente es el español, escrito en el código con `tr('...')`. `lib/core/i18n/en.dart` y `pt.dart` traducen
  cada texto; los marcadores van entre llaves (`{n}`) y se sustituyen con `tr('{n} libros', {'n': 3})`.
* El idioma se elige en Ajustes: el del sistema, español, inglés o portugués.
* `tool/guardianes/i18n.dart` falla si un texto no tiene traducción, si una traducción sobra o si los marcadores no
  coinciden.
* El texto de los libros no se traduce ni se toca: lo pinta el motor tal cual.
